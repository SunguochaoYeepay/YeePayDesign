# 页面族路由索引

本文件由 `admin-pc-ant-policy.json` 生成。页面族支持范围以 MCP 返回的实时策略为唯一依据；
不得依据项目提示、旧对话或客户端缓存判断是否支持。

| 业务证据 | 主页面族 | 读取包 | 当前状态 |
| --- | --- | --- | --- |
| 查询条件、结果列、表格、导出、分页 | `list` | `admin-pc-ant-list.md` | 可用 |
| 新增、编辑、配置、录入、提交 | `form` | `admin-pc-ant-form.md` | 可用 |
| 单据、账户、记录的查看与关联信息 | `detail` | `admin-pc-ant-detail.md` | 可用 |
| 完成、失败、处理中及恢复动作 | `result` | `admin-pc-ant-result.md` | 仅流程转场 |

选择规则：

- 当前只生成一个内容区时，只读取一个主页面族包。
- 提交后跳转下一步或显示异步校验，不等于当前页面要改为 `result`；它应是当前 Page Spec 的交互转场。
- 多步骤只在前后依赖明确时使用。
- 右侧说明或配图只在能帮助当前任务理解时使用，不是默认装饰。
- Page Spec 必须记录选择理由、未采用的候选能力和必要假设。
- 只有实时策略标记为“可用”的页面族可以走快速入口；其他页面族不能为了继续任务回退到全量读取原始资料。
